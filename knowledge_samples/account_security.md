# Account and Security Policy (Synthetic Demo Document)

Synthetic demonstration content for ResolveFlow.

## Password resets
- Customers can reset their own password via "Forgot password" on the login page.
- Support agents and automated systems must NEVER change, view, or reset
  customer credentials directly. All credential requests are escalated.

## Account changes
- Email address changes require verification from both the old and new address.
- Account deletion is irreversible and requires explicit human confirmation.

## Two-factor authentication
- 2FA is recommended for all accounts and required for admin roles.
- Losing a 2FA device requires identity verification by a human agent.

## Data access
- Customers may request an export of their data from Settings -> Privacy.
- Support agents cannot access customer message contents beyond ticket text.
